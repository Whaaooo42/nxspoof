Setup

Once per Mac, or if a setting gets reset. You won't need the steps below by hand: they're here so you know what happens.

The easy way: double-click NXSPOOF.app, open ⚙️ Configure, press 🛠️ Fix selected: one password in macOS's own window. It checks every step below, fixes B and the virtual cable, and says exactly what to type for the rest (the hotspot's name and password in C, and D on each console). Safe to run again: it only changes what's missing.

Setup and undo wait while NXSPOOF runs. Each writes its own log in the data folder (…-setup.log, …-uninstall.log). The first time setup changes the bridge, it notes how it was (mac_before.json), so Undo can put it back.

The steps

  1. A. Python. python3 --version in Terminal shows 3.9 or higher. If a window offers to install "command line developer tools", click Install. (Every double-click file checks this first and offers it.)
  2. B. Thunderbolt Bridge with a fixed address. System Settings → Network → Thunderbolt Bridge → Details… → TCP/IP: Configure IPv4 Manually · IP Address 172.16.0.1 (or the one chosen on Thunderbolt Bridge's line in ⚙️ Configure: 10.254.0.1, 192.168.254.1) · Subnet Mask 255.255.255.0 · Router empty → OK. Missing? Network → ⋯ → Add Service → Thunderbolt Bridge.

    Why: Internet Sharing needs something to share from. This is a dead link that goes nowhere, and a virtual cable (plugged in at every start) makes it look connected.

  3. C. Internet Sharing's settings. System Settings → General → Sharing → ⓘ next to Internet Sharing. NXSPOOF sets "from" (Thunderbolt Bridge, never an Ethernet plugged into your router) and "to" (Wi-Fi only) itself at every start. The Wi-Fi Options… are yours, set once; NXSPOOF only reads them:
    FieldSet to
    Network Nameyours to choose (NXSPOOF, for example): your Switches join it by this name
    Channel11 (or 6, 1: 2.4 GHz channels every Switch sees)
    SecurityWPA2/WPA3 Personal. Not "WPA3 Personal", which the Switch 1 can't use
    Password8+ characters

    If the form shows an old name, quit System Settings (⌘Q) and open it again.

  4. D. Join the hotspot on each console. System Settings → Internet → Internet Settings → your hotspot → password.

    ⚠️ If your home Wi-Fi is also saved on the console and in range, the console may join that instead and get real internet. Always check it's on the hotspot.

What setup checks

One step per requirement (setup/steps.py), each with a check, a fix when one is possible, and an explanation otherwise. To fix only some: setup --only bridge,cable; never one: --skip cable. The names: settings, python, bridge, cable, sharing, hotspot, ports, macfirewall, filezilla, consoles.

Removing NXSPOOF

  1. On the dashboard: ⚙️ Configure → ↩ Undo setup…, then choose: back to how your Mac was before NXSPOOF, or macOS's defaults.
  2. Close the dashboard, then delete the nx-spoof folder and ~/Library/Application Support/NXSPOOF.
  3. Optional: System Settings → Privacy & Security → Files and Folders: remove NXSPOOF.
